# PowerBI_Project
INTRODUCTION:  
Power BI is a powerful business intelligence tool developed by Microsoft that allows users to 
visualize, analyze , and share insights from data. In today’s data-driven world, organizations 
rely on clear and interactive reports to make better decisions. Power BI makes it possible to 
transform raw data into visually appealing dashboards that provide actionable insights. 

“BANK TRANSACTION DASHBOARD” 
INTRODUCTION: 
This dataset contains over 5,000 banking transactions collected for status analysis and location
based insights. Each row represents a unique transaction with details like amount, date, 
location, and account type. The data is used to detect the transaction status, visualize city-wise 
activity, and support decision-making for banking operations.
